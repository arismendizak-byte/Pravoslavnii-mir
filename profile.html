Аккаунт и синхронизация

Аккаунт необязателен. Локальные данные не отправляются на сервер автоматически: загрузка в аккаунт и восстановление на устройство выполняются только отдельными кнопками.

Ваш аккаунт

Ручная синхронизация «Мой ПМ»

Серверное состояние ещё не проверено.

Восстановление заменяет локальное состояние только после явного подтверждения. Stable IDs и unresolved legacy records сохраняются.

Восстановление доступа

Backend создаёт одноразовый recovery token; доставка письма подключается отдельно в production-инфраструктуре. В dev-режиме token может быть возвращён только для локальной проверки.
